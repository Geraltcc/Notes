1. 输出视频
```
event images (i++) {
  output_ppm (h);
}
#编译命令
qcc -O2 -Wall test1.c -o test1 -lm
#运行命令
./test > out.ppm 2 > log
#预览
animate out.ppm
#转换视频
ffmpeg -framerate 30 -i ux_%04d.png -c:v libx264 -pix_fmt yuv420p output.mp4

ffmpeg -framerate 120 -i ux_%04d.png -c:v libx264 -pix_fmt yuv420p k.mp4

ffmpeg -framerate 100 -pattern_type glob -i "ux_*.png" output.mp4

ffmpeg -framerate 30 -pattern_type glob -i 'out_frame/snapshot_*.png' -c:v libx264 -pix_fmt yuv420p test.mp4
```
