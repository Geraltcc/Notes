## 一、核心思路：沿流线方向的隐式 Picard 迭代

> **沿每一条从物面出发的流线进行一维隐式推进求解。**

### 步骤概览：
1. **流线提取**：从物面每个单元（或插值点）出发，沿当地速度方向 \(\frac{\mathbf{u}_e}{|\mathbf{u}_e|}\) 向外追踪一条流线，直到边界层外缘或计算域边界。

3. **在每条流线上建立隐式方程**：将方程 (1) 和 (12) 离散化为沿流线的一维隐式格式，使用 Picard 迭代线性化非线性项。
4. **迭代求解**：在全局范围内交替更新 \(\theta\) 和 \(H\)，直至收敛。

## 二、Picard 隐式离散与迭代格式

### 方程 (1) 的隐式格式
令 \(s\) 为沿流线的弧长坐标，则方程 (1) 可写为：
\[
A(\theta, H, \cdots) \frac{d\theta}{ds} + B(\theta, H, \cdots) \theta = RHS(\theta, H, \cdots)
\]
其中 \(A\) 和 \(B\) 为系数，\(RHS\) 为右端项（含 \(C_f, C_D\) 等）。

**Picard 线性化**：在第 \(k\) 次迭代中，所有非线性系数均用第 \(k-1\) 次迭代的值计算，得到关于 \(\theta^{(k)}\) 的线性微分方程：
\[
A^{(k-1)} \frac{d\theta^{(k)}}{ds} + B^{(k-1)} \theta^{(k)} = RHS^{(k-1)}
\]

**隐式离散**（以一阶迎风隐式为例，稳定且适合边界层推进）：
设流线上点 \(i=1,2,...,N\)（\(i=1\) 在物面），则：
\[
A^{(k-1)}_i \frac{\theta^{(k)}_i - \theta^{(k)}_{i-1}}{\Delta s} + B^{(k-1)}_i \theta^{(k)}_i = RHS^{(k-1)}_i
\]
整理得：
\[
\left( \frac{A^{(k-1)}_i}{\Delta s} + B^{(k-1)}_i \right) \theta^{(k)}_i - \frac{A^{(k-1)}_i}{\Delta s} \theta^{(k)}_{i-1} = RHS^{(k-1)}_i
\]
**形成三对角方程组**，沿每条流线可用 **Thomas 算法（TDMA）** 高效求解。

---

### 方程 (12) 的隐式格式
同理，方程 (12) 可写为：
\[
\frac{d\theta}{ds} + C(\theta, H, \cdots) \theta = \frac{C_f}{2}
\]
经 Picard 线性化后离散为：
\[
\frac{\theta^{(k)}_i - \theta^{(k)}_{i-1}}{\Delta s} + C^{(k-1)}_i \theta^{(k)}_i = \frac{C_f^{(k-1)}}{2}
\]
同样形成三对角系统求解。

## 三、在 Basilisk 自适应网格上的实施要点

- 每条流线独立求解，无需全局点序。只需保证在一条流线上点序沿流动方向即可。
- 对于有攻角的叶形，流线自然贴合物面弯曲，**无需特意对齐网格**。

### 3. **迭代流程**
```

    # 步骤1：更新所有辅助参数（H*, Hk, Cf, CD, ...）使用当前 θ 和 H

    # 步骤3：沿每条流线隐式求解 H (式12)

### 4. **边界条件**
- 物面（\(i=1\)）：\(\theta = 0\)（或极小值），\(H\) 由当地压力梯度与 Cf 关系给出初值。
- 边界层外缘（\(i=N\)）：可采用 Neumann 条件 \(\frac{d\theta}{ds}=0\)，或匹配外部无粘解。

### 5. **自适应网格下的并行策略**
- 每条流线求解独立，可并行化（OpenMP 或 MPI）。
- 每次迭代后，将 \(\theta, H\) 更新回网格节点（通过插值或投影），便于下一步流场耦合。

## 四、处理刚度与收敛加速

### 1. **松弛因子（Under-relaxation）**
- Picard 迭代可能收敛慢，加入松弛因子 \(\omega \approx 0.5 \sim 0.8\)：
  \[
  \theta^{(k)} = \omega \theta^{(k)}_{new} + (1-\omega) \theta^{(k-1)}
  \]

### 2. **隐式格式的优势**
- 一阶隐式格式无条件稳定，允许较大的 \(\Delta s\)（沿流线步长），避免显式 CFL 限制。
- 三对角求解计算量小，适合每条流线独立计算。

### 3. **初值选取**
- 首次计算可用 **简化模型**（如零压力梯度 Blasius 解）提供初值，加速收敛。
- 或从势流解 + 经验公式估算初始 \(\theta\) 和 \(H\)。

      H_new = /* 类似形式求解，用θ_new和梯度 */;
      
      // 5. 松弛更新
      double omega = 0.7; // 松弛因子
      theta[i] = omega*theta_new + (1-omega)*theta_old;
      H[i] = omega*H_new + (1-omega)*H_old;
      
      residual = max(residual, fabs(theta_new - theta_old));
    }
    
    // 6. 处理自适应网格：在细/粗网格边界同步
    boundary({theta, H}); // Basilisk边界同步
    restriction({theta, H}); // 限制到粗网格
    prolongation({theta, H}); // 延拓到细网格
  }
}
```

### 步骤3：局部时间步长计算
为了加速收敛，每个点使用自己的稳定时间步：
\[
\Delta \tau_i = \text{CFL} \cdot \min\left(\frac{\Delta x}{|u_i|}, \frac{1}{|B_i|}\right)
\]
其中 \(B_i\) 是方程的源项系数，CFL可以取2-5（隐式格式允许更大的CFL）。

## 四、优化收敛的策略

### 1. **多重网格加速**
虽然不能全局排序，但可以利用Basilisk的**自适应网格层级**做伪多重网格：
- 先在粗网格上快速达到近似解
- 将解插值到细网格作为初值
- 在细网格上精细化求解

### 2. **Jacobian-Free牛顿迭代**
结合点隐式和伪时间，近似实现牛顿迭代：
```c
// 在每个点上近似计算对角Jacobian
double J_theta = 1.0 + dtau * (∂RHS/∂θ - A * ∂(dθ/ds)/∂θ);
theta_new = theta_old - residual / J_theta;
```

### 3. **选择性隐式处理**
只对刚度大的项隐式处理：
- 对 \(B\theta\) 项隐式（通常刚度最大）
- 对流项和源项显式
- 梯度项用最新可用值

## 五、完整算法流程

```
初始化：从势流解或前一时间步获取θ₀, H₀
标记边界层区域（基于速度梯度或涡量）

while (不收敛且伪时间步<最大步数):
  1. 遍历所有边界层网格点（顺序无关）:
     a. 计算当地流线方向梯度（用当前场值）
     b. 计算所有辅助参数(H*, Hk, Cf, CD...)
     c. 点隐式更新θ: θ_new = f(θ_old, 梯度, 参数)
     d. 用新θ更新H: H_new = g(θ_new, H_old, 梯度)
     e. 松弛更新: θ = ωθ_new + (1-ω)θ_old
  
  2. 自适应网格操作:
     a. 在细化/粗化边界同步θ, H
     b. 必要时重新标记边界层
  
  3. 检查收敛:
     res = max(|θ_new-θ_old|, |H_new-H_old|)
     if res < tol: break
  
  4. 更新伪时间步（可选自适应时间步）

输出: 收敛的θ, H场，通过式(13)计算吹吸动量
```

## 六、在Basilisk中的具体实现建议

1. **数据结构**：
   ```c
   scalar theta[], H[], Hk[], Cf[], CD[];
   vector u_e[]; // 边界层边缘速度
   ```

2. **梯度计算**：使用`gradient`函数族，配合`fractional`权重处理切割网格

3. **并行化**：Basilisk的`foreach`循环自动支持OpenMP并行，点隐式天然适合并行

4. **自适应处理**：
   ```c
   // 在迭代中保持解的一致性
   boundary({theta, H});
   restriction({theta, H});  // 粗网格←细网格
   // 细网格的值通过prolongation自动获得
   ```

5. **收敛监控**：
   ```c
   double max_residual;
   foreach() 
     max_residual = max(max_residual, fabs(theta[] - theta_old[]));
   fprintf(stderr, "Iter %d, res = %g\n", iter, max_residual);
   ```

这种**点隐式伪时间推进**方法：
- ✅ 完全避免全局矩阵组装
- ✅ 天然适合自适应网格和无序点
- ✅ 能处理刚度问题（通过局部隐式）
- ✅ 易于并行实现
- ✅ 可以处理复杂几何和攻角

收敛速度可能比全局隐式慢，但实现简单、内存友好，非常适合在Basilisk这类自适应网格框架中使用。
